# Body Parts Fun Game (React + Tailwind + Framer Motion + PWA)

A kid-friendly drag-and-drop learning game for body parts.

## Tech
- React
- JavaScript (ES6)
- Tailwind CSS
- Framer Motion
- Vite PWA plugin

## Run
1. Install Node.js 18+.
2. In this folder run:
   - `npm install`
   - `npm run dev`
3. Open the local Vite URL in browser.

## Build PWA
- `npm run build`
- `npm run preview`

Install from browser menu (Add to Home Screen / Install App).
